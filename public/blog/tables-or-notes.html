A table, or a note?

October 2026 · Feito em Lisboa · 4 min read

In Lifebook, a note and a table are two shapes of the same idea: somewhere to set information down and find it again. A note is for words that run on. A table is for facts that repeat. Reach for the right shape and your Lifebook stays clear; reach for the wrong one and you spend your time fighting the format instead of using it.

The grain of each

A note has no structure to keep. You open it and write - a thought, a plan, a draft, a journal entry, a sheet of reference you will read from top to bottom. It bends to whatever you bring.

A table has a grain: columns you fill the same way each time, and rows you can line up and compare at a glance. It rewards you when the same kind of fact keeps coming back and you want to sort it, scan it, or add it up.

Neither is the tidier of the two. A table of loose, one-off entries is a cage. A note holding fifty repeating facts is a fog. The skill is simply matching the shape to the content.

When to reach for a note

Write a note when the content is words, not fields:

  • A journal entry, meeting notes, or a quick brain-dump.
  • A draft you are still thinking through - an email, a toast, a plan.
  • Reference you will read back, like a recipe or a how-to.
  • Anything where every entry is different and you would never line them up side by side.

The test: if you would read it, it wants to be a note.

When to reach for a table

Build a table when you are keeping a list of the same kind of item, each with a few details worth comparing:

  • Books and films: title, who, and whether you have got to it yet.
  • Trips: place, dates, who is coming.
  • A simple budget: what, how much, when.
  • A packing list, a guest list, clothes sizes - anything that reads as "one row per ___".

The test: if you would scan it, sort it, or count it, it wants to be a table.

How it works in Lifebook

  • Start a note - choose New note and write. That is the whole of it.
  • Turn a note into a table, or back. Every note can flip to a table and back again, so nothing is a dead end. When a note quietly fills with the same shape of fact over and over, switch it to a table. If a table turned out to be more than you needed, switch it back. Your content comes with it.
  • Keep the map and the territory apart, then join them. A table is the overview; a note is the depth. Link a busy row to the note that holds its detail, and each opens into the other - a table of clients up top, a full note behind each name.
  • File either into a Life Space, so it sits with the part of your life it belongs to and turns up where you expect it.
A rule of thumb: if you would read it, write a note; if you would scan it, build a table. And the day a note becomes a list of the same kind of item again and again, that is the moment to make it a table.

Most people end up with far more notes than tables, and that is right - a life is mostly words. But when a list starts to sprawl, the table is there to bring it to order, and you never have to decide perfectly up front. Start wherever is quickest, and let it change shape as it grows.
