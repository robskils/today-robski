Install Daybook as an app

October 2026 · Feito em Lisboa · 3 min read

Daybook lives in your browser, but it does not have to feel like a browser tab. In a couple of clicks you can install it as an app - its own icon, its own clean window, ready offline and able to send you notifications.

Daybook is a progressive web app, which is a plain way of saying it installs straight from the web with nothing to download from a store. Same Daybook, same sign-in - just in proper app clothing. Here is how, wherever you are.

On a computer

  • Chrome or Brave (Windows, Mac, Linux) - open daybook.fyi and look for the small install icon at the right of the address bar (a screen with a downward arrow). Click it, then Install. No install icon? Use the ⋮ menu → Cast, save and share → Install page as app (Brave: ⋮ → Install Daybook…).
  • Microsoft Edge - the ⋯ menu → Apps → Install this site as an app.
  • Safari on Mac (Sonoma or newer) - with Daybook open, the File menu → Add to Dock.

Daybook then opens in its own window and sits in your Dock, Taskbar or Start menu like any other app.

Nothing to download from a store. It installs straight from the web.

On a phone or tablet

  • iPhone and iPad - open daybook.fyi in Safari, tap the Share button (the square with an upward arrow), then Add to Home Screen.
  • Android - open daybook.fyi in Chrome, tap the ⋮ menu, then Install app (or Add to home screen).

You will get a Daybook icon on your home screen that opens full-screen, with no address bar in the way.

Why bother

  • One tap in. A real icon beats hunting for the right tab.
  • A calmer window. Full screen, no browser clutter around your day.
  • Works when the signal does not. The app keeps its shell ready, so a patchy connection does not leave you staring at a blank page.
  • Notifications. Once installed, you can let Daybook nudge you about what matters - on your terms, and off by default.

That is all there is to it. Install it once, and Daybook is there on the Dock or home screen whenever you need it - the same quiet, private home for your day, now a tap away.
